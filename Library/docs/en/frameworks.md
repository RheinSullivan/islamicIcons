# Frameworks

Islamic Icons is framework-agnostic. The core asset model is local SVG/WebP, while adapters make framework usage convenient.

## Canonical component syntax

```jsx
<Allah className="" size="" style="" />
```

## Native HTML syntax

```html
<islamic-icons categories="Allah" class="" size="" style="" />
```

Supported adapter areas include React/Remix, Vue/Nuxt, Svelte/SvelteKit, Angular and Astro. Plain HTML can consume the local assets without an adapter.

**Atsarul Mujahidin** (*آثَارُ المُجَاهِدِيْنَ - Traces of the Mujahidin*) is an open-source, framework-agnostic Islamic icon library providing 81+ authentic vector (SVG) and raster (WebP) files for modern digital products. It offers official integrations for all major frontend frameworks, web components, mobile environments, and backend services.

## Packages & Framework Integrations

Inspired by modular design systems, Atsarul Mujahidin provides zero-overhead entry points for every target environment:

| Package / Integration | Purpose | Status | Links |
| :--- | :--- | :--- | :--- |
| `atsarul-mujahidin` | Core package with metadata, catalog, and SVG exports | Ready | [NPM](https://www.npmjs.com/package/atsarul-mujahidin) · [Docs](https://atsarulmujahidin.rheinsullivan.web.id/en/docs) |
| `atsarul-mujahidin/react` | Native React & Next.js components with TypeScript definitions | Ready | [React Guide](https://atsarulmujahidin.rheinsullivan.web.id/en/docs/frameworks#react) |
| `atsarul-mujahidin/vue` | Native Vue 3 & Nuxt components | Ready | [Vue Guide](https://atsarulmujahidin.rheinsullivan.web.id/en/docs/frameworks#vue) |
| `atsarul-mujahidin/svelte` | Native Svelte 5 (Runes) & SvelteKit components | Ready | [Svelte Guide](https://atsarulmujahidin.rheinsullivan.web.id/en/docs/frameworks#svelte) |
| `atsarul-mujahidin/vanilla` | Framework-free Web Components for plain HTML and legacy apps | Ready | [Vanilla Guide](https://atsarulmujahidin.rheinsullivan.web.id/en/docs/frameworks#vanilla) |
| `atsarul-mujahidin/api` | REST API endpoints & CDN catalog for Flutter, Android, iOS, Python, Go, PHP | Ready | [API Guide](https://atsarulmujahidin.rheinsullivan.web.id/en/docs/frameworks#api) |

## Features

- **81+ Curated Islamic Icons** across 14 semantic categories (Mosque, Prayer, Quran, Ramadan, God, Prophet, Community, Flags, and Ornaments).
- **Component-First Architecture** with full TypeScript support and tree-shaking.
- **Cross-Platform Readiness** - Use as Svelte/React/Vue components, Web Components, raw SVGs, or query over REST API in Flutter, Android, iOS, and Python.
- **Multiple Style Variants** - Fill, Outline, and Multi-color styles matching real artwork geometry.
- **Source-Aware Provenance** - Comprehensive attribution metadata for all contributors and original design sources.
- **Solidarity for Palestine 🇵🇸 & Sudan 🇸🇩** - Dedicated symbols and solidarity assets for humanitarian causes.

## Installation

Install using your preferred package manager:

```bash
# Recommended: Bun
bun add atsarul-mujahidin

# npm
npm install atsarul-mujahidin

# pnpm
pnpm add atsarul-mujahidin

# yarn
yarn add atsarul-mujahidin

# Deno
deno add npm:atsarul-mujahidin
```

## Quick Start

### React / Next.js

```jsx
import { Kaaba } from 'atsarul-mujahidin/react/kaaba-fill';
import { MosqueSimple } from 'atsarul-mujahidin/react/mosquesimple-fill';
import { Quran } from 'atsarul-mujahidin/react/quran-fill';

export default function Header() {
  return (
    <nav>
      <Kaaba size={48} colors="#10b981" />
      <MosqueSimple size={48} colors="#3b82f6" />
      <Quran size={48} />
    </nav>
  );
}
```

### Vue 3 / Nuxt

```vue
<script setup>
import { Kaaba } from 'atsarul-mujahidin/vue/kaaba-fill';
import { MosqueSimple } from 'atsarul-mujahidin/vue/mosquesimple-fill';
import { Quran } from 'atsarul-mujahidin/vue/quran-fill';
</script>

<template>
  <nav>
    <Kaaba :size="48" colors="#10b981" />
    <MosqueSimple :size="48" colors="#3b82f6" />
    <Quran :size="48" />
  </nav>
</template>
```

### Svelte 5 / SvelteKit

```svelte
<script>
  import Kaaba from 'atsarul-mujahidin/svelte/fill/Kaaba';
  import MosqueSimple from 'atsarul-mujahidin/svelte/fill/MosqueSimple';
  import Quran from 'atsarul-mujahidin/svelte/fill/Quran';
</script>

<Kaaba size={48} colors="#10b981" />
<MosqueSimple size={48} colors="#3b82f6" />
<Quran size={48} />
```

### Plain HTML / Web Components

```html
<script type="module" src="https://cdn.jsdelivr.net/npm/atsarul-mujahidin@0.1.1/vanilla/atsarul-mujahidin.js"></script>

<atsarul-mujahidin variant="mosque" colors="#10b981" size="32">Masjid</atsarul-mujahidin>
<atsarul-mujahidin variant="quran" colors="#3b82f6" size="32">Al-Quran</atsarul-mujahidin>
```

### Mobile & Other Languages (Flutter, Android, iOS, Python, Go, PHP)

Use our CDN or standalone REST API:

```bash
# Start local API microservice
node node_modules/atsarul-mujahidin/api/server.js
```

Or consume raw SVGs via CDN:
```
https://atsarulmujahidin.rheinsullivan.web.id/api/icons/mosque-simple/fill.svg
```

## Repository Structure

```text
islamic-icons/
├── library/                 # Core npm package published as 'atsarul-mujahidin'
│   ├── api/                 # Universal REST API, static endpoints, and server
│   ├── assets/              # Master SVG and WebP artwork categorized by topic
│   ├── fill/                # Compiled ES module SVG strings for Fill variant
│   ├── outline/             # Compiled ES module SVG strings for Outline variant
│   ├── color/               # Compiled ES module SVG strings for Color variant
│   ├── react/               # Generated React JSX components
│   ├── vue/                 # Generated Vue 3 SFC components
│   ├── svelte/              # Generated Svelte 5 components
│   ├── vanilla/             # Web Component implementation
│   ├── scripts/             # Build, catalog, and validation pipelines
│   └── package.json         # Package configuration and export maps
├── web-docs/                # Public documentation and interactive catalog web application
│   ├── src/                 # SvelteKit application source
│   ├── static/              # Favicons, banners, and logos
│   └── svelte.config.js     # SvelteKit configuration
└── atsarulmujahidin_benner.png # Official repository banner
```
